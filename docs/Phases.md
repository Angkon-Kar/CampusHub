# Project Implementation Phases

- **Phase 1: Backend Foundation & Load Balancer**
  - Node.js + Express + MongoDB connection using `dotenv`.
  - Node `cluster` module for multi-core load balancing (keep `ENABLE_CLUSTER=false` for chat until sticky sessions are added).
  - URL unshortener & safety validator utility.
- **Phase 2: Firebase Auth & Custom MongoDB Sync**
  - Firebase (Google, GitHub, Email/Password). Apple is not used.
  - `/api/auth/sync`: sync Firebase users with MongoDB, unique `username`, Terms & Conditions, login providers.
  - Client pages: Login, Register, Complete profile.
- **Phase 3: Core Posts Engine**
  - CRUD endpoints with compound indexes (College, Dept, Session, Tags).
  - Custom text editor (no images, validated links) and live link validator.
  - Download lock for guests.
- **Phase 4: Profile, Achievements & Social Sharing**
  - `/username` route, achievements (`.reduce()` / `.filter()`), share modal.
- **Phase 5: Admin Panel & Analytics**
  - RBAC (Admin/Moderator), moderation queue, report handling.
  - Weekly/Monthly/Yearly analytics (aggregation + JS array methods).
- **Phase 6: Encrypted Socket.io Chat**
  - AES-256-GCM encryption/decryption in Node.js, Socket.io rooms, LinkedIn-style drawer.
